# 화면 글의 목소리 — 짧고, 한눈에, 게임답게

사람이 낱말 손질(배수 · 바꾸기 · 지키는 적 · ~ 모음 · 풀어 쓴 문장)을 해 보고 「별로야. 너무 어색해」라고 했다(2026-09-27). 검수해 보니 어색함의 뿌리는 셋이다.

## 어색했던 까닭
1. **모음이라는 말.** 한국어에서 「모음」은 먼저 모음(ㅏㅓㅗ)으로 읽힌다. 「뛰기 모음」 · 「폰 사슬 모음」 · 「같은 적 모음」은 이름이 아니라 설명문 조각이다.
2. **문장이 길고 설명투다.** 「나이트로 떨군 사슬이 끝나면 배수 ×1.5」, 「~되, ~ — 기물에 막히면 거기까지」, 「이 격언은 뛰기 모음을 한 칸 채운다」. 카드 글이 규칙서처럼 읽힌다. 같은 머리말(「떨군 사슬이 끝나면」)이 수십 번 되풀이된다.
3. **낱말 상자가 너무 많다.** 카드 하나에 상자가 넷까지 뜬다. 떨구기 · 사슬 · 값 · 배수처럼 첫 수업에서 이미 배운 기본 낱말까지 매번 풀어 화면을 덮는다.

## 기준

### 낱말
| 전 | 뒤 | 까닭 |
|---|---|---|
| 모음 | **시너지** | 롤토체스 · 여러 게임에서 익숙한 말. 「기사 시너지 2/4」가 곧바로 읽힌다 |
| 뛰기 · 가로세로 · 대각선 · 갈아입기 · 끊김 · 승급 · 폰 사슬 · 같은 적 | **기사 · 성채 · 사제 · 변신 · 희생 · 왕관 · 행진 · 사냥** | 이름은 명사 하나. 기사 = 나이트처럼 뛰는 것, 성채 = 룩처럼 가로세로, 사제 = 비숍처럼 대각선, 왕관 = 프로모션 · 퀸, 행진 = 폰. 무엇을 하는지는 낱말 상자가 말한다 |
| 「이 격언은 뛰기 모음을 한 칸 채운다」 | **「기사 +1」**(시너지 문양과 함께) | 카드 구석의 작은 칩으로 충분하다 |
| 바꾸기 | **버리기** | 발라트로 한국어판의 말. 손에서 하나를 골라 버리고 새로 뽑는다 |
| 배수 · 값 | 그대로 | 발라트로 한국어판도 배수. 값은 칩 자리 |
| 지키는 적 | 그대로 | 체스의 「지킴」. 단 「지켜진 칸」 · 「지키던 적을 먹어 잇는다」 같은 꼬인 문장은 풀지 말고 짧게 |
| 떨군 사슬 | **시작한 사슬** 또는 말하지 않기 | 「나이트로 떨군 사슬」 → 「나이트로 시작하면」 |
| 외통 | **체크메이트**, 짧게 쓸 곳은 **메이트** | 사람: 「용어가 너무 장기 용어」(2026-09-29). 체스를 둬 본 사람이면 곧바로 읽는 말. 카드 폭이 모자라면 메이트(메이트 사냥꾼 · 「메이트: 상금 +6」) |
| 명인 · 명인 대국 | **마스터 · 마스터전** | 체스의 마스터 칭호. 「대국」을 붙이면 길어 「~전」으로 줄였다. 우두머리 이름(기병대장 · 대가 …)은 그대로 |
| 정석 | **레퍼토리** | 바둑 말. 체스에서 한 사람이 늘 꺼내는 오프닝 묶음이 레퍼토리 — 판 끝까지 가는 큰 선택에 맞는다 |
| 묘수 | **전술** | 바둑 · 장기 말. 체스 퍼즐의 「전술(tactic)」 — 한 번 쓰고 사라지는 수 |
| 명국 · 명국 조각 | **명경기 · 명경기 조각** | 명국은 바둑 말. 불멸의 대국 · 오페라 대국 같은 체스의 명승부 |
| 승급 | **프로모션** | 체스 규칙 이름 그대로. 홀로 쓰면 판촉으로 읽히니 이름에는 결과(퀸)를 쓴다: 퀸의 잔치 · 퀸으로 가는 길 · 패스드 폰 |
| 단 0~8 | **레이팅** 800 ~ 2400(800 + 200 × 단) | 단은 바둑 · 장기 급수. 체스는 레이팅 숫자로 세기를 말한다. 표시만 바꾸고 저장 값은 단 그대로 |

### 문장
- **카드 효과는 「조건: 효과」 한 줄**, 20자 안팎. 예:
  - 기사도 「나이트로 시작: 배수 ×1.5」
  - 폰의 행진 「폰으로 시작: 값 +40」
  - 빠른 갈아입기 「모습이 바뀔 때마다 배수 +2」
  - 한결같음 「모습이 안 바뀐 사슬: 배수 ×3」
  - 각인 금 「사슬이 끝나면 상금 +2」 / 유리 「배수 ×2 · 가끔 깨진다」
  - 레퍼토리 기사 서약 「나이트 둘이 야간기사가 된다」
- 효과가 둘이면 「 · 」로 잇고 둘 다 짧게. 셋 이상이면 줄인다.
- 「~되」, 「거기까지」, 「~ 대신 ~」의 긴 꼬리, 괄호, 줄표(—)를 쓰지 않는다(줄표는 정말 필요할 때 한 번).
- 「~하면」보다 「~ 때마다」 · 「조건:」이 짧으면 그쪽.
- **행마 글은 두 문장까지, 짧게.** 그림이 설명의 주인이다.
  - 야간기사 「L자로 뛴다. 같은 방향으로 계속 더 뛸 수 있다」
  - 포 「기물 하나를 넘어서 먹는다」
  - 메뚜기 「앞의 기물을 넘어, 바로 뒤 칸을 먹는다」
  - 궁수 「두 칸 떨어진 적을 쏜다. 움직이지 않는다」
  - 유령 「룩처럼 가로 · 세로로 가며, 기물을 뚫고 지나간다」
  - 비숍 「대각선으로 미끄러져 먹는다」(「막히면 거기까지」는 그림이 보여 준다)
- 낱말 풀이 한 문장도 같은 목소리로 짧게: 「배수: 먹을 때마다 +1. 점수 = 값 × 배수」.

### 낱말 상자
- 카드 하나에 **최대 2개**.
- **기본 낱말은 상자를 띄우지 않는다**: 떨구기 · 사슬 · 값 · 배수 · 모습 · 먹기 · 손 · 주머니 · 수 · 목표 · 상금. 이 낱말들은 첫 수업이 가르치고, 낱말 풀이 화면에 있다. 글 안에서도 강조색을 빼거나 아주 옅게.
- 상자를 띄우는 것: 시너지 이름, 특수 기물 이름, 끊김 · 지키는 적 · 프로모션 · 체크메이트 · 증원 · 금빛 적 · 각인 · 혼 · 레퍼토리 · 전술 같은 드문 낱말.
- 자리는 레이아웃 규약(`docs/design-notes/layout.md` 「설명 자리 규칙」)을 따른다: 말풍선 바로 아래에 같은 폭으로 쌓이고, 판 틀은 왼쪽 칸 · 판 밖은 가리킨 것 바로 아래. (옛 「빈 쪽을 먼저 찾고 덮는 면적이 가장 적은 쪽」은 카드마다 자리가 튀어 버렸다.)

## 검수하는 법
글을 고칠 때마다 스크린샷으로 1배 화면을 보고, 이 질문에 모두 「예」인지 본다.
1. 처음 보는 사람이 이 카드를 **3초 안에** 알아듣나?
2. 소리 내어 읽어 어색한 곳(번역투 · 설명서투 · 꼬인 조사)이 없나?
3. 같은 머리말이 여러 카드에 되풀이되지 않나?
4. 낱말 상자가 필요한 것만 떴나, 화면을 덮지 않나?
