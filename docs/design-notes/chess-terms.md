# 체스 말 (CHM-24)

체스에 있는 개념은 체스 말로 부른다. 능력치는 이해하기 쉽게 쓰되 용어는 체스로 쓴다.

## 낱말

| 옛 말 | 체스 말 | 영어 | 까닭 |
|---|---|---|---|
| 외통 | **체크메이트**, 짧게 쓸 곳은 **메이트** | Checkmate · Mate | 장기 말. 체스를 둬 본 사람은 곧바로 읽는다 |
| 명인 · 명인 대국 | **마스터 · 마스터전** | Master · Master Match | 바둑 · 장기 칭호. 「마스터 대국」은 길어 「~전」. 우두머리 이름(촌장 · 기병대장 · 대가 …)은 그대로 |
| 정석 | **레퍼토리** | Repertoire | 바둑 말. 한 사람이 판마다 꺼내는 오프닝 묶음 = 판 끝까지 가는 큰 선택 |
| 묘수 | **전술** | Tactic | 바둑 · 장기 말. 체스 퍼즐의 tactic — 한 번 쓰는 수 |
| 명국 · 명국 조각 | **명경기 · 명경기 조각** | Classic · Classic Fragment(그대로) | 바둑 말. 불멸의 대국 · 오페라 대국 같은 체스 명승부 |
| 승급 | **프로모션** | Promotion(그대로) | 체스 규칙 이름. 홀로 이름에 쓰면 판촉으로 읽혀, 격언 이름은 결과(퀸)로 불렀다 |
| 단 0~8 | **레이팅** 800 + 200 × 단 (800 ~ 2400) | Rating | 단은 바둑 · 장기 급수. 표시만 바꾸고 저장 · 규칙 · 하네스는 단 그대로 |

그 밖의 낱말은 `voice.md` 낱말 표를 따른다.

## 낱말 풀이가 글에서 찾는 꼴(`src/ui/glossary.js` TERMS)

| id | 찾는 꼴 |
|---|---|
| mate | `/외통/` · Mate | `/체크메이트\|(?<!체인)메이트/` · Checkmate — 짧은 꼴도 찾고, 게임 이름 「체인메이트」에는 걸리지 않게 |
| master | `/마스터(?:전)?/` — 「마스터전」은 한 낱말로 |
| promote | `/프로모션\S*/` |
| joseki | `/레퍼토리/` · `/\brepertoires?\b/i` · Repertoire |
| tactic | `/전술/` · `/\btactics?\b/i` · Tactic |
| fragment | `/명경기 조각/` |

## 남긴 옛 말

- 코드 id · 변수 · 주석(`joseki` · `tactic` · `master` · `mate` · `promote` · `dan` · `run.josekis` · `records.mates` 등)과 테스트 이름 · 하네스 표 머리의 외통 · 명인 · 정석 · 묘수 · 명국 · 승급은 그대로다. 저장이 그대로 열리도록 id는 건드리지 않는다. 화면에 나오는 글에만 체스 말을 쓴다.
- 레이팅은 표시만 바꿨다. 저장 · 규칙 · 하네스는 단 그대로다.
- 상점의 주머니 기물 올리기 단추는 「올리기」(영어 Upgrade to)로 쓴다. 체스의 프로모션(끝줄에서 퀸)과 다른 일이다.
