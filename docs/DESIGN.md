# 체인메이트 (Chainmate) 설계

체스 기물로 하는 로그라이크 퍼즐. 발라트로의 뼈대(점수 = 합 × 배수, 한정된 플레이·버리기, 오르는 목표, 보스 규칙, 상점과 영구 조정자)를 참고해 체스의 말로 새로 짰다. 화면 톤과 스프라이트 원형은 `docs/mockup.html`(아티팩트 https://claude.ai/artifact/UtzvPMc4Lo3AXo7vKvFTDt).

## 뿌리 (모든 장치는 여기에 매달린다)

> **잡으면 그것이 된다.** 한 수 안에서 기물은 잡은 적의 모습으로 갈아입으며 판을 쓸어 낸다.

- 핵심 순환: 떨구기 → 먹기 → 갈아입기 → 이어 먹기 → (끊김 또는 막힘) → 점수 → 상점에서 사슬을 더 길고 무겁게.
- 새 장치에 묻는 두 질문:
  1. 떨구기 · 먹기 · 갈아입기 · 끊김 · 승급 · 외통 중 하나를 강하게 하거나 비트는가? (그냥 "점수 +"면 불합격)
  2. 아래 「세계의 말」로 설명되는가?
- 무작위는 두 곳에만 둔다: 주머니에서 손으로 뽑기, 증원(들어올 적). 판에 놓인 적은 전부 보인다(명인 「안개」 예외).

## 세계의 말

밤마다 열리는 끝나지 않는 기원. 여덟 관의 명인을 차례로 꺾는다. 화면 글은 이 말들 안에서만 쓴다.

| 말 | 뜻 |
|---|---|
| 판 | 한 번의 도전 전체(런) |
| 관 | 대국 셋 묶음(앤티). 1관~8관 |
| 대국 | 목표 점수가 있는 한 판(블라인드). 연습 · 정식 · 명인 |
| 명인 | 관의 우두머리. 규칙 하나를 비튼다 |
| 수 | 기물 하나를 떨궈 사슬을 푸는 것(플레이) |
| 무르기 | 손을 골라 버리고 다시 뽑기(버리기) |
| 손 · 주머니 | 핸드 · 덱 |
| 사슬 | 한 수 안의 연속 잡기 |
| 값 · 연쇄 | 점수의 두 인수(칩 · 배수) |
| 끊김 | 지켜진 적을 먹어 되잡힘 |
| 외통 | 킹을 먹음 |
| 격언 · 기보 · 각인 | 상점 물건(조커 · 행성 · 강화) |
| 상금 | 돈 |
| 오프닝 | 시작 주머니 변형(덱 선택) |
| 단 | 난이도 단계(스테이크) |

화면 글 규칙(작업 취향 공통): 조작법 설명 문구 금지, 설명서 말투·만든 쪽 용어(엔진, 시뮬, 스폰, 틱, 버프 등) 금지, 「A가 아니라 B」 문장 꼴 금지.

## 대국 규칙

> 시안(mockup)의 사슬 장면은 분위기용 그림이고 실제 규칙으로는 성립하지 않는다(c3이 노려짐). 규칙 판정은 이 문서를 따른다.

### 판과 좌표
- 8×8. `file` 0~7(a~h), `rank` 0~7(0이 내 쪽 아래). 칸 번호 `sq = rank*8 + file`.
- 판 위에는 적 기물만 있다. 내 기물은 사슬을 푸는 동안만 올라와 있다가 끝나면 내려간다.
- 적 폰은 아래(rank 감소)를 향한다: `(f±1, r−1)`을 공격. 내 기물이 폰 모습일 때는 위를 향한다: `(f±1, r+1)`로만 먹는다.

### 행마 (공격 판정)
- 나이트 L자, 킹 주변 8칸, 룩 가로세로·비숍 대각·퀸 둘 다 미끄러짐. 미끄러지는 선은 어떤 기물(적이든 내 기물이든)에 막힌다. 캐슬링·앙파상·2칸 전진 없음.

### 한 수
1. **떨구기**: 손에서 기물 하나를 골라 빈칸에 놓는다. 놓을 수 있는 칸 = 빈칸 ∧ 적 누구에게도 공격받지 않음 ∧ 그 자리에서 먹을 적이 하나 이상. 폰은 rank 7에 놓을 수 없다.
2. **먹기**: 현재 모습의 행마로 닿는 적 하나를 고른다. 적을 치우고 내 기물이 그 칸으로 간다.
   - 값 += 먹힌 기물의 값, 연쇄 += 1 (기본값, 아래 점수 계산에서 조정자가 더한다)
   - 모습 = 먹힌 기물의 종류 (갈아입기). 같은 종류를 먹으면 모습은 그대로(「갈아입기」 이벤트는 종류가 바뀔 때만).
   - 킹은 **아무도 지키지 않을 때만** 먹을 수 있다(응수로도 예외 없음). 먹으면 **외통**: 사슬과 대국이 즉시 끝나고 이긴다.
3. **응수와 끊김**: 먹은 직후(승급이 있으면 승급한 뒤), 그 칸을 노리는 적(노림수)이 있으면 다음 먹기는 **노림수 중 하나여야 한다**(응수). 지금 모습으로 노림수 중 하나라도 먹을 수 있으면 사슬은 이어지고, 하나도 먹을 수 없으면 **끊김**: 먹은 값·연쇄는 인정하고 사슬이 끝나며 내 기물은 되잡힌다(이번 대국에서는 사용된 것으로 처리).
   - 예: 비숍 모습이 된 칸을 대각선의 퀸이 노리면 그 퀸을 먹어야 한다(먹을 수 있으니 이어짐). 룩 모습이 된 칸을 나이트가 노리면 나이트를 먹을 수 없으니 끊김.
   - 노리는 적이 둘 이상이면 그중 하나만 먹으면 된다(먹은 뒤 새 칸에서 다시 판정).
   - 지키는 기물부터 치워 두는 순서가 퍼즐의 중심이다. 응수를 강요받는 칸은 붉게 보인다.
   - (이 규칙을 고른 이유: 「지켜지면 곧바로 끊김」으로 하면 같은 선을 쓰는 기물끼리(B→Q, R→Q, Q→Q, N→N…) 절대 이어 먹을 수 없어 사슬이 구조적으로 짧아진다. 응수는 체스다움과 긴 사슬을 같이 살린다.)
4. **승급**: 폰 모습으로 rank 7에 닿으면 곧바로 퀸 모습이 된다. 「승급」 이벤트. 응수 판정은 승급한 모습(퀸)으로 한다. (전설 「폰 여덟의 행진」은 폰으로 떨군 사슬의 승급 칸을 rank 5부터로 당긴다.)
5. 먹을 적이 없으면 사슬이 끝난다. 내 기물은 판에서 내려가 이번 대국의 「쓴 기물」로 간다.
6. 사슬이 끝나면 이번 수 점수 = 값 × 연쇄 를 누적 점수에 더한다.
7. **증원**: 수가 끝날 때마다 미리 예고된 칸에 적이 들어온다. 다음 증원 칸과 종류는 수를 두기 전부터 흐린 그림자로 보인다. 예고 칸이 그 사이 막혔으면 가장 가까운 빈칸.

### 대국의 끝
- 누적 점수 ≥ 목표 → 즉시 이김. 외통 → 즉시 이김(점수 상관없이).
- 수를 다 썼는데 목표 미달 → 판 끝(패배).
- 손에 떨굴 수 있는 기물이 하나도 없고 무르기도 없으면 → 패배.
- 이긴 뒤 보상: 대국 기본 상금(연습 3, 정식 4, 명인 3) + 남은 수당 1 + 적립(가진 상금 5당 1, 최대 5). 외통으로 이기면 +3. 목표를 ×5 넘기면 +1, ×10이면 +2.
- 명인 대국을 이기면 **명인의 상자**(1개 77% · 3개 20% · 5개 3%, 칸마다 상금 2 · 기보 한 레벨 · 각인 하나). 명인 기본 상금은 2a의 5에서 상자 몫만큼 뺐다(2b 하네스).
- **황금 기물**: 대국 시작 판의 킹 아닌 적 하나가 대국당 4%로 금빛. 먹으면 값을 한 번 더 받고, 이긴 뒤 금빛 꾸러미와 불멸의 기보 조각 기회(HOOKS.md).
- **사슬 평가**: 한 사슬에서 먹은 수가 3 · 5 · 8 · 12에 닿으면 「!」 · 「!!」 · 「!!!」 · 「∞」. 목표를 넘긴 비율 ×1 · ×2 · ×5 · ×10도 층마다 알린다.

### 손과 주머니
- 대국 시작 때 주머니 전체를 섞어 손 4개를 뽑는다. 수를 두거나 무르면 4개까지 다시 뽑는다. 주머니가 비면 손이 줄어든다.
- 대국마다 수 4, 무르기 3(한 번에 1~4개 버림).
- 시작 주머니(기본 오프닝): 폰 4 · 나이트 2 · 비숍 1 · 룩 1.

## 점수

값(합) × 연쇄(배수). 한 수 안에서 순서대로:
1. 각 먹기마다: 값 += 먹힌 기물 값(폰 10 · 나이트 30 · 비숍 30 · 룩 50 · 퀸 90 · 킹 150), 연쇄 += 1.
2. 먹을 때의 **모습**에 해당하는 기보 레벨이 있으면: 값 += 기보값 × 레벨, 연쇄 += 기보연쇄 × 레벨.
3. 격언의 먹기 반응(왼쪽부터).
4. 사슬이 끝난 뒤: 떨군 기물의 각인, 격언의 사슬 끝 반응(왼쪽부터). ×연쇄 격언은 여기서 곱한다.
5. 점수 = floor(값 × 연쇄).

화면은 한 칸씩 먹을 때마다 값·연쇄 숫자가 튀어 오르고, 사슬이 끝나면 곱해진 점수가 누적에 흘러 들어가는 순서로 보여 준다.

## 판(런)의 흐름

- 8관 × (연습 · 정식 · 명인). 명인 대국마다 규칙이 하나 붙는다. 8관 명인을 이기면 판을 이긴다. 이후 「끝없는 대국」으로 계속 가능.
- 연습 · 정식 대국은 건너뛸 수 있다. 건너뛰면 **패**(작은 보상 하나: 공짜 기보, 다음 상점 할인, 공짜 각인 등) 중 대국마다 정해진 하나를 받는다.
- 목표 점수(하네스로 맞춤, 2a): 관별 기준 B = [150, 600, 2000, 5200, 13000, 32000, 72000, 150000], 연습 ×1, 정식 ×1.5, 명인 ×2. 1관은 격언 없이도 넘고(상점 안 쓰는 봇 95%), 2~4관은 격언·기보를 제때 못 모은 판을 걸러 내고, 5~7관은 관마다 ×2.3~2.5로 올라 ×연쇄 격언과 기보를 갖춘 짜임만 따라간다. 끝없는 대국은 8관 뒤로 관마다 ×2.2.
- 대국판 생성: 적 수 = max(10, 8 + 관), 킹 1 필수. 킹은 처음부터 **셋이 지키고(3관부터 넷), 그중 하나는 폰**이다(폰 모습은 아래로 못 먹으니 그 폰을 마지막에 치우면 킹에 닿지 못한다). 하나만 지키게 두면 그 수비수를 먹는 순간 같은 선으로 킹에 닿아, 1관에서 첫 수 외통이 절반을 넘었다. 증원은 수마다 2. 주머니는 여섯 개 밑으로 줄일 수 없다(넷까지 줄이면 대국 끝에 손이 비어 막힘 패배가 9%).
- 외통은 드문 한 방으로 둔다: 판 안에서 외통으로 이기는 대국 약 3~5%, 첫 수 외통 3% 미만(하네스 측정). 목표 점수가 있으면 두 수 안팎에 대국이 끝나 수비수를 다 치울 틈이 적다. 그래서 외통은 짜릿한 예외로 두고, 「왕의 목」 같은 격언이 그 길을 여는 짜임이 된다.
  - 생성 검증: 시작 손에 대해 떨굴 수 있는 수가 최소 하나는 있어야 한다. 없으면 다시 만든다(시드 안에서 결정적으로).

## 상점 (대국을 이길 때마다)

- 진열 2칸(격언 · 기보 · 각인 · 기물이 섞여 나옴) + 꾸러미 2개 + 다시 진열(5, 누를 때마다 +1).
- 격언 칸 5(흑요 판본마다 +1, 전설 격언은 칸 밖), 소모품(기보 · 각인 두루마리) 칸 2. 격언은 팔 수 있다(산 값의 절반, 판본 값 포함). 전설은 못 판다.
- 진열 격언에 4%로 **판본**(은박 연쇄 +5 · 자개 값 +50 · 무지개 연쇄 ×1.5 · 흑요 격언 칸 +1). 진열 칸 3% · 꾸러미 4%로 불멸의 기보 **첫 조각**. 황금 기물을 먹은 대국 뒤엔 공짜 **금빛 꾸러미**(판본 붙은 격언 셋 중 하나). 확률 층은 HOOKS.md 「드문 것들의 사다리」.
- 꾸러미: 기물 꾸러미(3개 중 1개를 주머니에), 기보 꾸러미(3중 1), 각인 꾸러미(3중 1, 손 대신 주머니 전체에서 대상 선택).
- 기물 조작: 승급(주머니 기물 하나의 종류를 한 단계 위로 P→N/B→R→Q), 버리기(주머니에서 빼기).

| 다시 생각 | 무르기로 버린 기물마다 이번 대국 값 +5(누적) | 무르기 |
| 빈 주머니 | 주머니 남은 기물 하나당 연쇄 +1 | 주머니 |
| 작은 주머니 | 주머니가 8개 이하면 연쇄 ×1.5 (2a의 ×2는 봇 주머니가 늘 6개라 조건이 늘 참, 산 판 승률 35%로 홀로 높아 낮췄다) | 주머니 |
| 증원 환영 | 방금 들어온 적을 먹으면 값 +40 | 증원 |
| 그림자 읽기 | 증원이 두 수 앞까지 보인다 | 증원 |
| 상아탑 | 상아 각인 기물로 떨군 사슬 연쇄 +5 | 각인 |
| 금고 | 사슬이 끝날 때 먹은 수만큼 상금(대국당 최대 5) | 먹기 |
| 기보 수집가 | 기보를 쓸 때마다 이 격언 연쇄 +1(영구 누적) | 기보 |
| 대국의 기억 | 이 판에서 외통 한 번마다 연쇄 ×0.5 누적(×1부터) | 외통 |

## 기보 (행성 카드) — 모습 6종

쓰면 그 모습의 레벨이 1 오른다. 그 모습으로 먹을 때마다 값 += a×레벨, 연쇄 += b×레벨.

| 모습 | a | b |
|---|---|---|
| 폰 | 10 | 1 |
| 나이트 | 15 | 1 |
| 비숍 | 15 | 1 |
| 룩 | 20 | 1 |
| 퀸 | 25 | 2 |
| 킹 | — | — (없음) |

## 명인 (보스) — 8

관마다 무작위 하나(같은 판에서 겹치지 않음). 8관은 「대가」 고정.

| 명인 | 비튼 규칙 |
|---|---|
| 철벽 | 적 폰은 좌우 옆 칸도 지킨다 |
| 안개 | 위 세 줄의 적이 가려져 있다. 내 기물의 행마가 닿는 칸만 드러난다 |
| 거울 | 한 사슬에서 같은 모습으로 두 번 갈아입을 수 없다 |
| 모래시계 | 수 3 |
| 무거운 손 | 손 3 |
| 침묵 | 가장 왼쪽 격언이 꺼진다 |
| 앙갚음 | 끊긴 사슬의 점수가 반 |
| 대가 | 킹이 둘이다 (「기보 무시」까지 붙이면 8관에 온 짜임의 점수가 ×0.06이 되어 판 승률 0.6% — 벽이 되어 뺐다) |

## 판 밖에 남는 것 (힘은 남기지 않는다)

- 기록(최고 점수 한 수, 최고 관, 판 수, 이긴 판), 도감(격언 · 명인 · 오프닝을 처음 볼 때 채움).
- 오프닝 해금(시작 주머니 변형): 기본 / 런던(폰 5 · 비숍 2) / 시실리안(폰 3 · 나이트 3, 손 5) / 퀸스 갬빗(폰 3 · 퀸 1, 수 3) / 룩 엔딩(룩 2 · 폰 4, 격언 칸 4) 등. 조건은 과제(예: 외통 10번).
- 단 1~8(난이도): 한 판 이기면 다음 단. 단마다 규칙 하나 누적(목표 ×1.25, 증원 +1, 상점 가격 +1, 무르기 −1 …).
- 오늘의 대국: 날짜 시드로 모두 같은 판.

## 구조

바닐라 JS ES 모듈, 빌드 없음. `python3 -m http.server`로 연다. 잿길(`~/workspace/projects/ashway`)의 구조를 따른다.

```
index.html  style.css
src/
  main.js          브라우저 진입: 루프, 입력, 화면 전환
  sim/             화면과 무관한 규칙. DOM·canvas 접근 금지. Node에서 그대로 돈다.
    rng.js         시드 난수 (mulberry32), 하위 스트림 분기
    board.js       판, 공격 판정, 떨굴 칸
    setup.js       대국판 짓기(적 수 · 킹 수비 · 적의 무게). 대국 시작과 전설 「오페라」의 판 다시 채우기가 같이 쓴다
    chain.js       사슬 진행(먹기·갈아입기·끊김·승급·외통)과 점수 이벤트
    battle.js      대국: 손·주머니·수·무르기·증원·승패
    run.js         판(런): 관·대국·상점·보상 흐름
    shop.js  scoring.js  ...
  data/            등록 데이터. 규칙 코드는 여기 id만 보고 동작한다.
    pieces.js maxims.js charts.js(기보) engravings.js masters.js openings.js
    editions.js(격언 판본) legends.js(불멸의 기보: 명국 · 재현 판정 · 전설 격언)
  render/          sim 상태를 읽어서 그리기만 한다.
tools/
  sim.mjs          화면 없이 N판을 돌리는 하네스 + 봇(최선 사슬 탐색)
test/              node --test
```

- 모든 무작위는 `rng`에서. 같은 시드 + 같은 선택 = 같은 결과.
- 상태 변경은 명령 객체로만: `{ type: 'drop', handIndex, sq }`, `{ type: 'capture', sq }`, `{ type: 'discard', handIndices }`, `{ type: 'buy', slot }` … 봇과 화면이 같은 명령을 쓴다.
- 내부 해상도 480×270, 정수배 확대 + 레터박스, `image-rendering: pixelated`.
- 글자는 캔버스 안에서 Galmuri11 12px로 그린다(한글 포함). 알파를 문턱값으로 잘라 도트처럼 또렷하게.
- 기물 스프라이트 16×22, 칸 28px, 판 224px(가운데). 모양 마스크(`#` 몸, `d` 새김)에서 테두리·빛·그늘을 자동으로 만든다. 원형은 mockup의 `SPR`·`TONE`·`sprite()`.
