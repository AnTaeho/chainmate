# 밤샘 A — 화면

브랜치 `night/1`. 규칙 층(`src/sim`, `src/data`)은 건드리지 않았다(`git diff main -- src/sim src/data` 비어 있음).

## 만든 것

| 자리 | 파일 |
|---|---|
| 진입 · 확대 · 입력 | `index.html` `style.css` `src/main.js` — 480×270 캔버스, 장치 화소 기준 정수배(작으면 비정수) + 레터박스, `image-rendering: pixelated`. 마우스 좌표는 `getBoundingClientRect`로 게임 좌표에. 오른쪽 누르기는 판 위 표시만(`docs/design-notes/layout.md` 「판 위 표시」). 터치도 누르기로 |
| 그리기 | `src/render/` — `sprites.js`(mockup SPR · TONE 이식, 캐시, 톤 w · b · g(황금 적) · s(은빛) · q(금빛)), `text.js`(Galmuri11 12px를 오프스크린에 그려 알파 > 0.5로 잘라 캐시, 굵게는 Bold), `gfx.js`(상자 · 점선 · 선 · 글자 · 기물), `palette.js` |
| 화면 흐름 | `src/ui/app.js` — 화면 전환, 명령(`applyRun`) 한 곳, 저장, 막간 차례(보상 → 상자 → 전설 → 상점), 알림, 흔들림, 말풍선 |
| 조작 | `src/ui/ui.js` — 즉시 모드 구역(누르기 · 끌기 · 말풍선). 구역 id가 연기 시험의 이름표 |
| 연출 | `src/ui/anim.js` — Seq(대국 사건을 차례로) · Fx(조각 · 반짝 · 떠오르는 글자). 연출 속도 설정이 곱해진다 |
| 화면 | `src/ui/screens/` — title · select · battle · reward · chest · legend · shop · pack · result · pause · settings |
| 저장 | `src/ui/save.js` — 명령마다 판 상태(JSON) 자동 저장, 판이 끝나면 지움. 설정 따로. 모두 try/catch |
| 도구 | `tools/smoke.mjs` + `tools/fakedom.mjs`(`npm run smoke`), `tools/shots.mjs`(전역 Playwright) |

대국 화면은 명령을 보내고 돌아온 사건 배열을 차례로 연출하는 동안 「보이는 판」을 따로 그린다. 연출이 끝나면 규칙 상태에서 다시 읽는다(2b 보고서: 상록 `redrop`, 오페라 `refill` 뒤에도 같은 길).

```
한 수 연출(×1) 평균 2.70s · 최대 3.82s (49수)
방문 화면: title select battle pause settings reward shop pack chest result legend
이어 하기: 확인 · 설정: 확인 · 격언 끌기: 확인
예외 0 · 3.6s
SMOKE OK
```
- 세 판: 봇 명령(`tools/bot.mjs` `decideBattle`)을 손 누르기 → 칸 누르기로 바꿔 둔다. 상점은 진열 · 꾸러미 · 두루마리(각인은 대상 누르기) · 승급 · 팔기 · 다시 진열 · 격언 끌기를 누른다.
- 셋째 판은 전설 셋(상록 · 오페라 · 불멸)을 쥐여 줘 다시 떨구기 · 판 다시 채우기 · 끊김 넘기기 연출을 지난다(8관까지 이김).
- 첫 상점에서 앱을 새로 부팅해 「이어 하기」로 같은 국면 · 관 · 상금이 돌아오는지 본다.
- 실패 조건: 예외, 못 간 화면, 이어 하기 실패, 한 수 연출 > 4초(×1), 프레임 p99 > 16ms.
- 스크린샷: `docs/shots/` 00~18(`node tools/shots.mjs`, 페이지 오류 0). 정한 안은 `docs/shots/README.md`.

## 내가 정한 것

- **손 고르기는 모드 없이**: 하나 들면 떨굴 칸이 빛나고, 여럿 들면 무르기 단추가 붉게 켜진다. (버림: 떨구기/무르기 전환 단추 — 컨트롤이 스스로 설명되게.)
- **먹을 적은 흔들리기만**: 칸을 칠하지 않는다. (버림: 금빛 칸 — 사슬 길의 금빛 테와 섞인다.)
- **격언 카드는 이름 + 동사**, 효과 글은 말풍선. (버림: mockup식 카드 위 짧은 효과 글 — `src/data` 글을 그대로 써야 하는데 112px에 안 들어간다.)
- **한 수 연출 예산**: 쌓인 연출이 1.2초를 넘으면 뒤 걸음을 줄여 간다(최소 2%), 곱 · 첫 외통은 그대로. 같은 순간의 점수 반응(격언 여럿)은 한 걸음. (버림: 먹을 때마다 ×0.88 — 오페라 사슬이 6초를 넘었다.) 연출 중 누르거나 키를 치면 ×5로 빨리 감는다.
- **증원 그림자 55%**(두 수 앞 30%). (버림: mockup 35% — 밝은 칸에서 상아처럼 보였다.)
- **퀸 스프라이트**: 구슬과 가운데 뿔을 세웠다. (버림: 원형 — 1배에서 룩과 섞였다.)
- **값 · 연쇄 상자**: 1만부터 12.3K · 4.5M. (버림: 상자 넓히기 — 왼쪽 판 폭 유지.)
- **명인 규칙**: 대국 시작 띠 2.2초 + 왼쪽 판 이름(말풍선). 관 선택 카드에 규칙 글 전부.
- **막간 차례**: 대국 승리 보상 → 명인의 상자 → 전설 → 상점. 조각은 알림 띠(비막음). 조각 띠(모은 수)는 격언 칸 머리 오른쪽, 올리면 조각 셋과 재현 조건(첫 조각 뒤에만).
- **저장은 명령마다**(사슬 한가운데 포함). 이어 하면 먹을 칸이 그대로 흔들린다. (버림: 수 끝 · 상점 행동만 — 사슬 중간에 닫으면 그 수를 잃는다.)
- **Enter**: 막간은 다음, 관 선택은 두기, 상점은 나가기, 대국에서는 먹을 칸이 하나뿐일 때 먹기.

## 알려진 문제 · 남은 것

- 소리 없음(B). 사슬 평가 · 넘친 목표는 글자만(B에서 키운다). 전설 완성 장면은 이름 · 이야기 · 금박 카드까지(명국 마지막 수 재생은 B).
- 끝없는 대국은 결과 화면 「계속 두기」로 들어가지만 관 표시 외에 따로 만든 것은 없다(D-9).
- 관 선택 국면의 두루마리 쓰기 · 격언 팔기(규칙은 허용)는 화면에 없다. 상점에서 한다.
- 화면을 사람 손으로 해 본 적은 없다(클라우드). 스크린샷과 연기 시험으로만 봤다.
