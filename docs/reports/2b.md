## 2. 공개 API · 상태 추가 (화면 단계가 읽을 것)

### 명령
| 명령 | 국면 | 뜻 |
|---|---|---|
| `{ type: 'redrop', sq }` | battle (`b.status === 'chain' && b.chain.awaiting`) | 전설 「상록」: 멈춘 사슬의 기물을 지금 모습 그대로 다시 떨군다. `legalCommands`가 돌려준다 |
| `{ type: 'sell', index }` | **pack**에서도 | 금빛 꾸러미의 격언을 칸이 찬 채로 받으려면 먼저 판다(전설은 못 판다: `canSell(m)`) |
| `{ type: 'pick', index }` | pack | 옵션 종류가 늘었다: `maxim`(금빛 꾸러미, `edition` 붙음) · `fragment`(`legend`) |
| `{ type: 'buy', slot }` | shop | 진열 물건 종류 `fragment { legend, price }`, 격언에 `edition` |

### 상태
- 판(run): `fragments: { [명국 id]: { first, feat, gold } }`, `legends: [id]`, 격언 명세 `{ uid, id, data, edition, paid, legendary? }`(전설은 `legendary: true`, 격언 칸 수와 따로 오른쪽 끝). `run.shop.packs`에 `{ kind: 'golden', price: 0 }`, `run.shop.goldenFragment`. 로그 한 줄(`run.log[]`)에 `goldenSeen · golden · overflow · grades{'!':n,…} · chest(개수)`.
- 대국(battle): `golden`(먹은 황금 기물 수), `overflow`(0·1·2·5·10), 판 칸 `{ t, id, born, gold? }`, `rules.openKings`(오페라). 대국 기록 한 줄(`b.history[]`) = `chainSummary`: `piece sq value mult score reason money captures transforms promotions forced caps cuts mates golden refills redrops move`.
- 사슬(chain): `cuts · mates · refills · redrops · awaiting · golden`, `flags.promoteFrom`.
- 모두 JSON 왕복 안전(테스트 「저장」).

### 함수 · 상수
- `run.js`: `maximCapacity(run)` · `maximCount(run)` · `hasMaximRoom(run, edition)` · `canSell(m)` · `legendInfo(id)` · `maximInfo(id)`(전설도) · `CHEST` · `REWARD.overflow`.
- `battle.js`: `GOLDEN.chance` · `OVERFLOW_TIERS` · `overflowTier(score, target)`.
- `chain.js`: `GRADES` · `gradeOf(n)` · `chainRedrops(t)` · `chainRedrop(t, sq)` · `chainSummary(c, move)` · `PROMOTE_RANK`.
- `solver.js`: 줄(line) 원소가 수(먹을 칸) 또는 `{ type: 'redrop', sq }`. `lineCommands(line)`으로 명령 배열. `bestMove(b, { rank })` — 줄 평가 덮어쓰기(결과 `r.h` = chainSummary).
- `shop.js`: `rollEdition` · `maximPrice(id, edition)` · `fragmentOffer(run, rng, source)` · `weighted`, `SHOP.editionChance · fragmentChance · fragmentPrice · goldenRarity · goldenFragmentChance`.
- `setup.js`(새): 대국판 짓기(`generateBoard(b, rng, reserve)` 등, battle.js가 다시 내보낸다).
- `data/editions.js`: `EDITIONS` · `EDITION_BY_ID` · `editionSpec(m)` · `editionSlots(m)`. `data/legends.js`: `LEGENDS`(`id name year story text verb feat source check(h)`) · `LEGEND_BY_ID` · `OPERA_REFILLS`.
- 새 훅(`scoring.js`): `onMate`(ctx.keepGoing()) · `onChainStop`(ctx.redrop()). 규칙 깃발: `rules.openKings`, `chain.flags.promoteFrom`.

### 새 이벤트 (applyRun / apply가 돌려주는 배열)
| type | 어디서 | 필드 | 화면 |
|---|---|---|---|
| `grade` | 먹기 | `n`(3·5·8·12) `mark`('!'·'!!'·'!!!'·'∞') | 평가 표기 · 테두리 · 흔들림 |
| `golden` | 먹기 | `sq` `piece` (뒤이어 `score { src: 'golden', value }`) | 금빛 부서짐 |
| `capture` | 먹기 | 기존 + `gold` | |
| `mate` | 먹기 | `sq` (오페라면 뒤에 `refill`이 오고 `end`가 없다) | |
| `refill` | 오페라 외통 뒤 | `sq`(내 기물 칸) `count`(몇째) `enemies` | 판 다시 채우기. 새 판은 대국 상태 `board` |
| `redropReady` | 상록 | `form` `reason`('cut'·'blocked') `squares[]` | 떨굴 칸 표시 |
| `redrop` | 상록 | `piece`(모습) `sq` | |
| `overflow` | 수 끝 | `tier`(1·2·5·10) `score` `target` — 한 수로 여러 층을 넘으면 층마다 | 누적 숫자 불붙음 |
| `reward` | 대국 승리 | 기존 + `overflow`(상금 덤) | |
| `chest` | 명인 승리 | `count`(1·3·5) `tier`('common'·'uncommon'·'rare') `cells[5]`({ lit, item }) `items[]` | 릴. 불 켜진 칸은 가운데부터(1: [2], 3: [1,2,3], 5: 전부), 왼쪽부터 멈추면 된다 |
| 상자 물건 | 명인 승리 | `money { src: 'chest', money }` · `chart { form, level }` · `engrave { piece, pieceId, eng }` | |
| `edition` | (상자 판본 칸, 지금 무게 0) | `uid` `id` `edition` | |
| `goldenPack` | 황금 기물을 먹고 이긴 뒤 | `fragment`(꾸러미에 첫 조각이 드나) | 상점에 금빛 꾸러미 |
| `packOpen` | 꾸러미 | 기존, `kind: 'golden'` 가능, 옵션 `maxim{id,edition}` · `fragment{legend}` | |
| `fragment` | 사기 · 고르기 · 재현(사슬 `end` 뒤) · 황금 | `legend` `part`('first'·'feat'·'gold') `have{first,feat,gold}` | 조각 연출. `first`면 재현 조건(`LEGEND_BY_ID[id].feat`)을 드러낸다 |
| `legend` | 셋째 조각 직후 | `legend` `uid` | 명국 마지막 수 재생 · 금박 격언 낙하 |
| `maxim` | 사기 · 고르기 | 기존 + `edition` | |

## 4. 정한 수치와 까닭

### 새 보상을 다 얹었더니 판 승률 12% → 55% — 절제 실험 (smart, seed 7, 80판씩)
판 봇은 돈에 아주 민감하다. 공짜 보상 하나가 판 승률을 10%p씩 올렸다. 하나씩 끄고 켜며 깎았다(원문 두 줄째만, 파일 전체는 이 세션의 작업용).

| 실험 | 판 승률 | 전설 완성 |
|---|---|---|
| 새 보상 전부 끔(판본 0 · 조각 0 · 황금 0 · 상자 0 · 넘침 덤 0) | 12.5% | 0.0% |
| 초안 전부(상자 칸 기보 40 · 상금4 25 · 각인 20 · 판본 15, 넘침 ×2 +1 · ×5 +2 · ×10 +3, 판본 8%, 조각 3%/5%) — 40판 | 55.0% | 10.0% |
| 초안에서 넘침 덤만 끔 | 41.3% | 7.5% |
| 초안에서 상자만 끔 | 22.5% | 8.8% |
| 상자 가볍게(상금2 45 · 기보 30 · 각인 10 · 판본 15) + 넘침 ×5 +1 · ×10 +2 | 41.3% | 10.0% |
| + 명인 기본 상금 2, 조각 2%/3% | 33.8% | 8.8% |
| 판본 4% · 조각 차례 고정 · 명인 3 · 작은 주머니 ×1.5 | 25.0% | 7.5% |
| 그 위에서 판본 0 | 21.3% | 7.5% |
| 그 위에서 상자 끔 · 명인 5 | 10.0% | 6.3% |
| **상자에서 판본 칸을 뺌(상금 60 · 기보 30 · 각인 10), 명인 3** | 15.0% | 5.0% |
| 상자 상금 70 · 기보 30, 명인 2 | 12.5% | 6.3% |

- **상자의 판본 칸**이 가장 셌다: 가진 격언에 곧바로 붙어 은박(연쇄 +5)이 1~4관을 공짜로 넘긴다. 뺐다(코드는 남아 있고 무게 0).
- **판본 8% → 4%**: 8%에서 판 봇의 81%가 판본 격언을 가졌다. HOOKS 「귀함 칸당 ~5%」를 귀한 격언(칸당 2.75%) + 판본(칸당 2.2%)의 합으로 읽었다. Balatro도 판본 조커는 ~4%.
- **넘침 덤 ×5 +1 · ×10 +2**: ×2부터 주면 이긴 대국의 절반이 덤을 받아 판 승률 +14%p. 이제 이긴 대국의 ~15%만 받는다(최대 2).
- **명인 기본 상금 5 → 2**: 상자 기댓값 ≈ 1.5칸 × (상금 2 · 기보 3어치 · 각인 3어치) ≈ 3.6. 2 + 3.6 ≈ 2a의 5. 3으로 두면 300판 24.0%.
- **작은 주머니 ×1.5**: 2a에서 판 봇 주머니가 끝에 평균 6.0개라 「여덟 이하」가 늘 참 = 조건 없는 ×2. 산 판 승률이 평균의 3.5배(35.2% / 10.0%)였고, ×2인 채 새 보상을 얹은 실험에서는 76.9%까지 올랐다. ×1.5로 1.8배(아래 최종 표).
- **조각 차례 첫 → 재현 → 금빛**: 아무 차례로 모이게 두면 재현 전에 먹은 황금 기물이 셋째 조각을 미리 채워 smart도 10%.
- **첫 조각 진열 3% · 꾸러미 4%**: HOOKS의 3~5% 안. smart는 판의 ~68%가 첫 조각을 한 번은 가진다(넉넉해 보이지만 재현 · 금빛 두 관문이 뒤에 있다).
- **금빛의 부름 10%**: 기본 4%로는 노리기 정책이 첫 조각 · 재현을 모은 판(48%) 중 금빛을 먹은 판이 14%뿐이라 전설 6.7%에 그쳤다(아래 「부름 없이」 300판). 넣고 나서 17.0%. 재현까지 해낸 판에서만 황금 기물이 잦아지니 운보다 의도에 기운다. 기본 4%(사다리)는 그대로.
- **오페라에 「지켜진 킹도 먹는다」**: 원문대로(외통하면 다시 채움)만 두면 킹 수비 셋 · 넷 아래 외통이 대국당 3~5%라 첫 손 최선 수 평균이 전설 없을 때와 똑같았다(903 → 903). 넣고 나서 5101.
- **풀이기 마디 예산 10000**: 오페라 + 각인 「깃」이 겹친 판에서 한 수 탐색이 수백만 마디로 불어나 하네스 일꾼이 한 판에 30분 넘게 멈췄다(seed 7633541). 예산을 넘기면 가지마다 첫 수만 따라 줄을 끝까지 채운다. 보통 한 수는 100~200마디라 영향 없음(대국 하네스 main과 같은 값). 다시 채운 판은 (시드 · 수 · 채움 · 칸 · 규칙 · 관) 열쇠로 기억해 쓴다.

| smart 판 승률 10~20% | **24.3%** | 넘침. 전설 판 몫(8.7% × 96%)이 ~8%p, 전설 없는 판 17.5% |
| 전설 판이 훨씬 잘 이김 | 96.2% / 76.5% | 맞음 |
| 작은 주머니가 홀로 세지 않게 | 산 판 승률 42.6%(평균 24.3%의 1.8배, 2a 3.5배) | 여전히 윗줄(변덕 · 희생과 비슷) |

지시대로 수치는 그대로 두었다. 다음에 고칠 방향:
1. **금빛의 부름 10% → 6~7%**: smart도 재현까지 가는 판이 28%라 부름의 덕을 같이 본다. 부름을 낮추거나, 부름을 「hunt가 더 하는 행동」(예: 첫 조각을 산 뒤 재현 조건을 드러내는 것 외에, 조각을 가진 명국의 재현 과제를 대국 앞에 고르는 것)에 묶으면 smart 5% · hunt 15%로 벌어질 것.
2. **smart 첫 조각 줄이기**: smart도 판의 68%가 첫 조각을 한 번은 가진다. 진열 3% → 2%로 내리면 smart 쪽이 더 줄고(hunt는 다시 진열로 메운다).
3. **판 승률 24%**: 전설 몫을 빼면 17.5%라 전설 확률을 1·2로 낮추면 20% 안으로 들어온다. 그래도 높으면 명인 기본 상금 2 → 1, 또는 금빛 꾸러미 등급을 흔함 쪽으로.
4. **작은 주머니**: ×1.5도 1.8배. 조건을 「여섯 이하」로(주머니 최소 6이라 봇이 늘 닿는다) 하기보다, 연쇄 ×(1 + 0.1×(9 − 가진 기물))처럼 줄일수록 오르게 바꿔 결정을 만드는 쪽을 권한다.

## 6. 모호했던 것과 정한 것

- **판본은 언제 듣나**: Balatro처럼 그 격언 자리에서. 사슬 끝에 격언 바로 뒤에서 한 번(격언이 조건을 못 채워도 판본은 듣는다 — 판본은 격언 칸의 빛깔이라서).
- **흑요 칸**: 흑요 격언은 제 칸을 가져오므로 칸이 차도 산다. 흑요를 팔면 칸이 줄어 격언이 칸보다 많아질 수 있다(그럼 살 수만 없다).
- **전설 6번째 칸**: 격언 칸 수와 따로 오른쪽 끝. 전설이 둘 완성되면 둘 다 들어온다(아주 드묾). 팔 수 없다.
- **조각 차례**: HOOKS의 첫/둘째/셋째를 차례로 읽었다(첫 → 재현 → 금빛). 황금 기물이 조각을 줄 명국이 없으면: 첫 조각이 하나도 없는 판만 금빛 꾸러미에 첫 조각 50%.
- **첫 조각 나오는 곳**: 진열(불멸 · 오페라), 기물 꾸러미(폰 여덟), 기보 꾸러미(세기), 각인 꾸러미(상록) — 명국 이야기와 가까운 것으로.
- **재현 판정**: 사슬이 끝난 뒤 사슬 요약으로. 불멸 「끊김 없이」는 넘긴 끊김(희생 · 은 등)도 끊김으로 셌다. 오페라 「첫 수에 외통」은 대국 첫 수에서 외통이 한 번이라도 났으면.
- **오페라 외통 뒤 모습**: 킹을 먹었으니 킹 모습(잡으면 그것이 된다). 외통 이벤트는 내되 대국은 이기지 않는다(점수로 이긴다). 「외통으로 이김」 격언(외통 사냥꾼 · 왕의 목 · 대국의 기억)은 오페라 사슬에서는 듣지 않는다. 새 판은 (대국 시드, 몇째 수, 몇째 채움)으로 정해 풀이기가 그린 판과 실제 판이 같다. 사슬당 세 번.
- **오페라에 「지켜진 킹도 먹는다」를 더함**: 원문 효과만으로는 거의 안 듣는다(4절). HOOKS를 크게 바꾸는 선택이라 문서에 까닭을 적었다.
- **세기의 대국 「곱으로 쌓인다」**: 사슬 끝에 ×1.5^n(n = 퀸 모습으로 먹은 수). 먹는 순간마다 곱하면 사이의 +1이 곱해지지 않아 약하고 순서에 흔들린다.
- **상록 「떨굴 칸을 다시」**: 지금 모습 그대로(갈아입은 모습을 잇는 쪽이 뿌리에 맞다), 끊김 · 막힘 뒤 한 번, 외통 뒤는 없음. ×연쇄 격언은 두 사슬이 다 끝난 뒤 한 번. 다시 떨굴 칸은 보통 떨구기 규칙(깃 각인 반영).
- **폰 여덟 「rank 5부터」**: 좌표 rank 5(여섯째 줄) 이상. 적 폰을 그 줄에서 먹어 폰 모습이 되면 곧바로 승급한다(기존 규칙이 끝줄 폰을 먹을 때 그렇듯).
- **넘친 목표 상금**: 「작게, 상한」 — ×5 +1 · ×10 +2(4절). 외통으로 목표 밑에서 이기면 층 0.
- **명인의 상자 결과와 순서**: 결과(개수 · 칸마다 물건)는 판 시드 × 관. 릴 연출 순서는 화면 몫이라 칸 배치(가운데부터 불)만 정했다.
- **황금 기물을 먹고 진 대국**: 판이 끝나므로 보상 없음.

## 7. 범위 밖에서 본 것

- **판 봇이 돈에 너무 민감**: 적립(5당 1) 구조 탓에 공짜 상금 몇 원이 몇 관 뒤의 격언 하나가 된다. 화면 단계에서 사람이 해 보면 체감이 다를 것 — 3단계 뒤 사람 판으로 한 번 더 재는 게 좋다.
- **smart 봇은 기보 꾸러미에서 조각을 거의 안 고른다**(기보가 늘 점수를 올려서): smart에서 세기의 대국 첫 조각 0. hunt는 55~59.
- **하네스 시간**: 전설(특히 오페라 · 상록)을 가진 판은 상점 평가마다 풀이기를 수백 번 돌려 판당 수십 초. 일꾼 하나가 끝에 혼자 남아 300판이 20~40분. 짜임 평가 캐시를 판 단위로 넓히거나 전설 판은 K를 줄이면 빨라진다.
- **건너뛰기 패**(「step 2b에서 늘린다」 주석)는 이번 목록에 없어 손대지 않았다.
- 명인 1~7 통과율 90~97%(2a 관찰 그대로).
