## 이렇게 열어서 이렇게 논다

```
npm run serve        # → http://localhost:8000
```
1. 타이틀에서 **새 판** → 오프닝(처음엔 기본만) · 단(처음엔 「없음」) → **두기**. 오늘의 대국은 날짜마다 모두 같은 판.
2. 관 선택: 연습 · 정식 · 명인 세 장. 연습 · 정식은 건너뛸 수 있다(패를 받는다). 명인 카드에 초상과 규칙.
3. 대국: 오른쪽 아래 **손**의 기물을 누르면 들리고, 떨굴 수 있는 칸이 빛난다 → 빛나는 칸을 누르면 떨군다 → **흔들리는 적**을 눌러 한 칸씩 먹는다. 먹을 때마다 값 · 연쇄가 튀고, 모습이 바뀐다. 붉은 빗금 = 노림수(응수 — 그중 하나를 먹어야 산다). 사슬이 끝나면 값 × 연쇄가 부딪혀 점수로 흘러든다. 손을 여럿 들고 **무르기**.
   - 키: 1~5 손 · Space 무르기 · Enter(먹을 칸이 하나뿐일 때 먹기 · 막간 다음) · Esc 내려놓기/멈춤 · 오른쪽 누르기 = Esc. 연출 중 누르면 빨리 감는다.
4. 이기면 보상 줄 → (명인이면) 명인의 상자 릴 → 상점: 진열 · 꾸러미 · 다시 진열, 격언은 끌어 순서를 바꾸고 눌러 판다, 두루마리는 눌러 쓴다(각인은 주머니에서 대상), 주머니 기물을 눌러 승급 · 버리기.
5. 8관 명인(대가)을 이기면 판 승리 → 계속 두기(끝없는 대국). 결과 화면에 최고 한 수가 작은 판에 되풀이된다.
6. 설정: 소리 · 음악 · 연출 속도 ×1/×2/×4 · 흔들림 · 큰 글자 · 한국어/English. 판은 명령마다 저장되어 닫았다 열어도 **이어 하기**.
