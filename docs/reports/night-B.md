# 밤샘 B — 연출과 소리

HOOKS.md 「의식」 표를 화면과 소리로 옮겼다. 규칙 층은 그대로(`git diff main -- src/sim src/data` 비어 있음).

## 의식 표 → 만든 것

| 순간 | 화면 | 소리(`src/audio/audio.js`) |
|---|---|---|
| 먹기 | 기물이 0.12초 미끄러짐, 먹힌 적이 도트 조각 14개로 부서져 떨어짐(중력), 칸 번쩍, 1px 흔들림 | 사슬 길이만큼 장음계로 한 칸씩(도레미파솔라시 → 다음 옥타브), 세모파 + 네모파 배음 |
| 갈아입기 | 가로 1 → 0 → 1 뒤집힘(0.1초) 동안 은빛(`s` 톤), 끝에 은빛 반짝 | 짧은 「촥」(잡음 쓸기 + 높은 미끄럼) |
| 사슬 평가 | ! · !! · !!! · ∞ 큰 글자가 판 오른쪽 위에 쾅(처음 한 박 크게). 판 테두리 불빛 흰 → 금 → 붉은 금 → 무지개(사슬 끝까지 남고 끝나면 사그라듦). 흔들림 1 · 2 · 3 · 4px | 평가마다 3 · 4 · 5 · 7음 아르페지오, ∞은 반짝이 |
| 끊김 | 멈칫(0.12초, 모든 연출 정지), 노린 적에서 붉은 선 · 칸에 붉은 금, 내 기물이 흐려져 사라짐 | 낮은 둔탁음 |
| 승급 | 기물이 금빛(`q` 톤)으로 솟았다 내려앉으며 퀸, 금빛 반짝 · 「승급」 | 종 두 번 |
| 외통 | 먹힌 킹이 제 칸에서 천천히 쓰러짐(0.55초), 멈칫 0.25초 + 연출 0.5초, 큰 글자 「외통」 | 낮은 화음 + 북 + 종 |
| 점수 합산 | 값 상자와 연쇄 상자가 가운데로 모여 금빛 곱 상자로 터짐(금빛 점 16) → 곱이 점수 칸으로 흘러가며 숫자가 빠르게 오름 | 쓸기 → 쿵 → 째깍 여덟 |
| 목표 넘김 | 점수 칸에 불이 붙음(불꽃 점이 오름, ×1 · ×2 · ×5 · ×10마다 더 많고 굵게, ×10은 흰 불). 층을 넘는 순간 「목표 달성 / 목표 ×N」 글자 + 판 테두리에서 번지는 고리 + 흔들림 | 올라가는 화음 + 쓸기(층마다 길게) |
| 대국 승리 보상 | 줄이 0.32초마다 하나씩 | 줄의 상금 수만큼 동전 하나씩(최대 여섯) |
| 명인의 상자 | 다섯 칸 릴이 돌다 왼쪽부터 0.42초마다 멈춤, 불 켜진 칸에 물건. 3개면 금빛 번쩍, 5개면 화면 전체 금빛 1.2초 + 흔들림 | 칸마다 딸깍, 불 켜진 칸은 딸깍 + 종(칸마다 높아짐), 3개 반짝이, 5개 팡파르 |
| 황금 기물 먹기 | 금빛 점 폭발 + 금가루가 튀었다 천천히 내려앉음 | 높은 방울 소리 |
| 조각 · 전설 | 조각이 판 가운데(상점은 산 카드)에서 호를 그리며 조각 띠로 날아가 반짝. 전설: 금빛 멈춤 → 명국의 마지막 2~3수를 작은 판에 다시 둠(`src/ui/replays.js`, 외통이면 킹이 쓰러지고 #, 폰 여덟은 금빛 퀸 셋) → 금박 격언이 위에서 떨어져 여섯째 칸에 박힘 → 전설 효과 글 | 전용 한 소절(느린 금빛 선율 + 종) |
| 판본 | 은박 = 가로로 흐르는 흰 빛줄기, 자개 = 색이 도는 얼룩 점, 무지개 = 테 두 겹이 색 순환, 흑요 = 검은 카드 + 보랏빛 테 + 보랏빛 빛줄기 | |

- 음악: 대국(A 단조 저음 84bpm, 사슬 2 · 4 · 6부터 화음 · 박 · 아르페지오 층 · 한 옥타브 위), 명인 대국(D 단조 반음 섞인 96bpm, 처음부터 화음), 상점(C 장조 112bpm), 타이틀 · 결과(느린 화음). 16걸음을 0.2초 앞서 예약.
- 첫 누르기(마우스 · 키 · 터치) 전에는 AudioContext를 만들지 않는다. 설정: 소리 · 음악 크기(0~10).
- 연출 속도(×1 · ×2 · ×4)가 대국 연출 · 효과 · 보상 줄 · 상자 릴 · 꾸러미 뒤집기 · 전설 장면에 곱해진다. 연출 중 누르거나 키를 치면 ×5 빨리 감기. `prefers-reduced-motion`이면 흔들림 · 멈칫 · 점수 불꽃을 끈다.

## 내가 정한 것
- **먹기 음계는 장음계**, 한 옥타브(7음)를 넘으면 다음 옥타브. (버림: 반음씩 — 12먹기까지 올라도 한 옥타브라 오름이 덜 느껴진다.)
- **평가 테두리는 사슬 끝까지 남긴다**. (버림: 글자와 함께 1초 만에 사라짐 — 「지금 !!」인 걸 보면서 다음 먹기를 고르게.)
- **점수 불꽃은 층마다 양 · 굵기**, ×10은 흰 불. (버림: 테두리 색만 — 넘친 만큼 축하가 보이지 않았다.)
- **멈칫은 실시간**(연출 속도로 나눔): ×4에서도 끊김 · 외통의 멈춤이 사라지지 않게 짧게 남는다.
- **전설 장면의 명국 수는 상징**: 실제 기보의 마지막 2~3수에서 기물 몇만(`replays.js`에 출처 수). 세기의 대국은 피셔(흑)를 내 빛깔로 그렸다.
- **음악 층은 사슬 먹은 수로**: 2 · 4 · 6. (버림: 평가(3 · 5 · 8)에 맞추기 — 평가 소리와 겹쳐 층이 들리지 않았다.)

## 알려진 문제
- 소리는 클라우드에서 들어 보지 못했다(가짜 WebAudio로 예외만 확인). 크기 · 음색은 사람 귀로 한 번 맞춰야 한다.
- 전설 장면의 작은 판은 20px 칸에 16×22 기물이라 위가 칸 밖으로 3px 나간다(윗줄은 판 틀에 걸친다).
