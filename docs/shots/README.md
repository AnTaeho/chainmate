# 화면 시안 · 스크린샷

`node tools/shots.mjs`로 다시 찍는다(Playwright chromium, 저장소 의존성 없음). `<이름>.png`는 480×270 원본, `@3x`는 3배 확대.

## 정한 안 / 버린 안 / 이유

| 자리 | 정한 안 | 버린 안 | 이유 |
|---|---|---|---|
| 격언 카드(대국 오른쪽) | 이름(굵게) + 둘째 줄에 동사(판본이면 판본 이름, 전설이면 「전설」). 효과 글은 올리면 말풍선 | mockup처럼 카드에 짧은 효과 글 | `src/data`의 효과 글(규칙: 그대로 쓴다)이 112px 카드에 들어가지 않는다. 줄이면 데이터와 화면 글이 갈라진다 |
| 무르기 단추 | 「손」 줄 오른쪽, 돌아가는 화살 + 「무르기」. 손을 하나 이상 고르면 붉게 켜진다 | 왼쪽 판 수·무르기 구슬 칸을 단추로 | 손 바로 위라 고르고 누르는 손길이 짧다. 구슬은 남은 수를 보여 주는 데만 쓴다 |
| 손 고르기 | 누르면 들리고(여럿 가능), 하나만 들렸을 때만 떨굴 칸이 빛난다 | 떨구기 · 무르기 모드 전환 단추 | 모드 없이 「하나 = 떨구기, 여럿 = 무르기」로 컨트롤이 스스로 설명된다 |
| 먹을 적 | 1px 위아래로 흔들린다(떨굴 칸처럼 칸을 칠하지 않는다) | 먹을 칸도 금빛으로 칠하기 | 칸을 칠하면 사슬 길(금빛 선 · 테)과 섞인다. 기물이 움직이면 「누를 것」이 기물이라는 게 보인다 |
| 증원 그림자 | 점선 테 + 흐린 적(55%), 두 수 앞은 30% | mockup의 35% | 밝은 칸 위 35% 흑단이 상아(내 기물)처럼 보였다 |
| 값 × 연쇄 상자의 큰 수 | 1만부터 12.3K · 4.5M 꼴 | 상자를 넓히기 | 왼쪽 판 폭(112)을 지키려고. 점수 칸은 전부 쓴다(1,234,567) |
| 한 수 연출 길이 | 한 수에 쌓인 연출이 1.2초를 넘으면 뒤 걸음을 줄여 간다(곱 · 외통은 그대로). 같은 순간의 점수 반응은 한 걸음 | 먹을 때마다 ×0.88 | 긴 사슬(오페라 · 상록)이 25초까지 늘었다. 짧은 사슬은 제 속도, 긴 사슬도 ×1에서 4초 안(연기 시험이 잰다) |
| 명인 규칙 | 대국 시작에 판 위 띠(명인 이름 + 규칙 글 2.2초), 왼쪽 판에 이름(올리면 말풍선) | 화면 한쪽에 늘 규칙 글 | 480×270에 늘 둘 자리가 없다 |
| 멈춤 | Esc(손을 들었으면 먼저 내려놓기), 오른쪽 위 세 줄 단추, 오른쪽 누르기 | 단추만 | 마우스만 쓰는 사람도 닿게 |
| 퀸 스프라이트 | 꼭대기 구슬 + 가운데 뿔을 세운 왕관(`00-sprites`) | mockup 원형 그대로 | 1배 화면(사슬 모습 줄 · 기보 카드)에서 퀸의 뾰족 왕관이 룩의 성가퀴와 섞여 보였다 |
| 황금 적 | 흑단 몸 + 금빛 테(`g`), 몸에 반짝이는 점 | 몸 전체를 금빛 | 금빛 몸은 승급한 내 기물(`q`)과 겹친다. 적은 늘 검은 몸 |
| 격언 아이콘 | 카드 오른쪽 12×12(격언 칸 · 진열 카드 가운데 · 도감) | 아이콘 없이 이름만 | 이름을 읽기 전에 「무엇」인지 눈에 들어오게. 짧은 카드(칸이 여섯 넘으면)에서도 이름과 같이 선다 |
| 명인 등장 | 대국 시작 띠에 초상(2배)이 오른쪽에서 미끄러져 들어오고 이름 · 규칙 글(세 줄까지) | 따로 막간 화면 | 한 번 더 누르게 하지 않으려고. 띠는 2.6초 뒤 사라지고 그동안에도 둘 수 있다 |
| 관 선택 명인 보상 | 「$2 + 상자」 한 줄 | 따로 「이기면 명인의 상자」 줄 | 새 명인 규칙 글이 길어져(네 줄) 자리를 비웠다 |
| 결과 화면 | 왼쪽 기록, 오른쪽 작은 판(칸 16px)에 이번 판 최고 한 수를 되풀이 | 기록만 | HOOKS 「이번 판 최고 한 수(재생 가능)」 |
| 손 들썩임 | 2.5초 동안 아무것도 들지 않으면 손 카드가 차례로 2px 들썩이며 금빛 테 | 「기물을 고르세요」 같은 글 | 화면 글 규칙(조작법 글 금지). 누를 곳이 손이라는 것을 움직임으로 |
| 영어 | 같은 배치에 글만 바꿈(`23-en-title` · `24-en-battle` · `25-en-setup`). 좁은 자리는 짧은 꼴(「Hall 1 · Practice」, 무르기 = Redraw) | 영어용 배치 | 한 배치로 두 말. 길이가 넘친 곳만 틀로 줄였다 |
