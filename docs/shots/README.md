# 화면 시안 · 스크린샷

`node tools/shots.mjs`로 다시 찍는다(Playwright chromium, 저장소 의존성 없음). `<이름>.png`는 480×270 원본, `@3x`는 3배 확대. 화면마다 따로 찍는 도구는 `tools/shots-*.mjs`, 규약은 `docs/design-notes/layout.md`.

## 처음 정한 안과 이유

| 자리 | 정한 안 | 이유 |
|---|---|---|
| 먹을 적 | 칸을 칠하지 않고 기물이 1px 위아래로 흔들린다 | 칠하면 사슬 길(금빛 선 · 테)과 섞인다. 누를 것이 기물이라는 게 보인다 |
| 증원 그림자 | 점선 테 + 속에 성긴 점을 둔 흑단 윤곽 + 흔들리는 ▼, 두 수 앞은 윤곽도 점선 · 속 비움. 들어올 때 위에서 14px 떨어진다 | 반투명 흑단은 갈색 기물로, 속이 빈 윤곽은 내 기물(상아)로 읽혔다 |
| 지키는 적 | 빗금 + 지키는 적에서 내 기물로 흐르는 2px 붉은 끊어진 선(기물 위, 양 끝은 몸을 비켜서). 먹을 수 없으면 어두운 붉은색 | 붙은 적이 많아 기물 밑 1px 선은 가려졌다 |
| 판의 길 | 관 선택 아래 「N관 / 8관」 + 구슬 여덟, 8관은 붉은 왕관. 대국 화면은 제목 한 줄 | 「어떻게 이기냐」는 물음에 답하는 자리. 대국 화면엔 늘 둘 자리가 없다 |
| 큰 수 | 값 × 배수 상자는 1만부터 12.3K · 4.5M, 점수 칸은 전부(1,234,567) | 왼쪽 칸 폭(112)을 지킨다 |
| 한 수 연출 길이 | 쌓인 연출이 1.2초를 넘으면 뒤 걸음을 줄여 간다(곱 · 체크메이트는 그대로) | 긴 사슬도 ×1에서 4초 안(smoke가 잰다) |
| 마스터 등장 | 대국 시작 띠에 초상이 미끄러져 들어오고 이름 · 규칙 글, 2.6초 뒤 사라지며 그동안에도 둘 수 있다 | 한 번 더 누르게 하지 않는다 |
| 멈춤 | Esc(든 손이 있으면 먼저 내려놓기) · 오른쪽 위 세 줄 단추 · 오른쪽 누르기 | 마우스만 쓰는 사람도 닿게 |
| 퀸 스프라이트 | 꼭대기 구슬 + 가운데 뿔을 세운 왕관 | 1배에서 뾰족 왕관이 룩의 성가퀴와 섞였다 |
| 금빛 적 | 흑단 몸 + 금빛 테 + 반짝이는 점 | 금빛 몸은 프로모션한 내 기물과 겹친다. 적은 늘 검은 몸 |
| 격언 아이콘 | 카드의 12×12 아이콘(격언 칸 · 진열 · 도감) | 이름보다 먼저 「무엇」이 눈에 들어오게 |
| 결과 화면 | 왼쪽 기록, 오른쪽 작은 판에 이번 판 최고 한 수를 되풀이 | HOOKS 「이번 판 최고 한 수(재생 가능)」 |
| 손 들썩임 | 2.5초 동안 아무것도 들지 않으면 손 카드가 차례로 2px 들썩이며 금빛 테 | 조작법 글 대신 움직임으로 누를 곳을 알린다 |
| 영어 | 같은 배치에 글만 바꾸고, 넘친 곳만 틀로 줄인다 | 한 배치로 두 말 |
